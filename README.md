# 업무 인수인계 대시보드

학교 담당 업무를 정리해 두고, 다음 담당자에게 **파일 하나로** 넘겨주는 윈도우 프로그램입니다.

받는 분은 Python도, 개발 도구도 설치할 필요가 없습니다. **설치파일 하나면 끝납니다.**

---

## 🚀 그냥 쓰고 싶다면 (대부분 여기만 보면 됩니다)

**만들어진 설치파일이 이미 올라가 있습니다. 내려받아 실행하기만 하면 됩니다.**
이 문서 아래쪽의 명령어들은 **볼 필요 없습니다.** 프로그램을 고칠 때만 쓰는 것들입니다.

### 1단계 — 설치파일 내려받기

👉 **[여기를 눌러 최신 설치파일 받기](https://github.com/sced9120/work-dashboard/releases/latest)**

열린 페이지를 아래로 내리면 **Assets** 라는 목록이 있습니다. 거기서 하나를 고르세요.

| 파일 | 어떤 경우에 |
|---|---|
| `WorkDashboard-Setup-2.3.0.exe` | **보통은 이것.** 설치하면 바탕화면에 아이콘이 생깁니다 |
| `WorkDashboard-Portable-2.3.0.exe` | 학교 PC라 설치가 막혀 있을 때. 설치 없이 그 파일만 더블클릭 |

크기는 약 100MB라 내려받는 데 1~2분 걸릴 수 있습니다.

### 2단계 — 실행하기

받은 파일을 더블클릭합니다.

> **"Windows의 PC 보호" 라는 파란 창이 뜨면?**
> 고장난 게 아닙니다. 개인이 만든 프로그램이라 마이크로소프트에 등록돼 있지 않아서 나오는 안내입니다.
> 창에서 **추가 정보** → **실행** 을 누르면 그대로 진행됩니다.

관리자 권한은 필요 없습니다.

### 3단계 — 쓰기

설치가 끝나면 바탕화면 아이콘을 더블클릭.
이후 사용법은 **[사용안내.md](사용안내.md)** 에 화면별로 정리해 두었습니다.

**여기까지가 전부입니다.** 아래 내용은 프로그램을 수정하거나 새 버전을 만들 때만 필요합니다.

## 2.3.0 — 입력이 막히던 문제, 그리고 화살표

### 고친 것

**어떤 작업을 하고 나면 입력창에 글자가 안 쳐지던 문제.** 주제를 지운 뒤 검색창,
학습을 시작하려다 취소한 뒤 숫자칸 — 원인이 둘이었습니다.

1. **운영체제의 confirm() 창.** 일렉트론에서 그 창을 닫고 나면 화면이 글쇠 입력을
   못 받는 일이 있습니다. 프로그램 안에 그리는 창으로 모두 바꿨습니다
   (`src/lib/confirm.tsx`). 생김새도 프로그램과 맞고, 무엇을 지우는지 여러 줄로
   찬찬히 보여 줄 수 있습니다.
2. **학습이 끝나지 않은 것으로 남던 문제.** 2.2.0 에서 넣은 학습 진행 표시가,
   도중에 무엇이 잘못되면 '학습 중' 인 채로 굳어 그 화면의 입력칸을 모두 잠갔습니다.
   `try/finally` 로 어떤 경우에도 풀리게 했습니다.

### 워크플로우

| | 설명 |
|---|---|
| **선이 상자를 피해 갑니다** | 위 상자에서 두 칸 아래로 이으면 사이에 낀 상자를 뚫고 지나가 선이 보이지 않았습니다. 이제 **직각으로 꺾어 옆으로 비켜** 갑니다. 비킬 쪽은 걸린 상자의 왼쪽·오른쪽 가운데 가까운 쪽을 고릅니다 |
| **화살표 지우기** | **선을 누르면** 파랗게 바뀌고 가운데에 **[−]** 와 **[✎]** 가 뜹니다. [−] 를 누르면 지워지고, [✎] 로는 "예 / 아니오" 같은 말을 붙입니다. 예전에는 지울 방법이 사실상 없었습니다 |

## 2.2.0 — 학습이 화면을 따라다닙니다

| | 설명 |
|---|---|
| **학습 진행 띠** | 공문을 학습시키는 동안 **어느 화면으로 넘어가도** 위쪽에 띠가 붙어 있습니다. 몇 건 중 몇 건까지 갔는지, 지금 어느 파일인지, 몇 건을 찾았는지가 보이고, 거기서 바로 **[멈추기]** 하거나 **[보러 가기]** 로 돌아갑니다 |
| **찾은 것이 안 사라집니다** | 예전에는 학습을 걸어 두고 다른 화면에 갔다 오면 **찾아낸 업무가 통째로 사라졌습니다.** 분석은 계속 돌지만 결과를 받을 곳이 없어졌기 때문입니다. 이제 한 건이 끝날 때마다 화면 밖에 담아 두어, 오갔다 와도 그대로 있습니다 |
| **보관 문서 학습에도 학년도** | [🗄 저장된 문서 학습]에서 **뽑아낸 업무를 몇 학년도로 매길지** 고를 수 있습니다. 기본은 *공문에 매겨 둔 학년도를 따름* 이고, 학년도가 없는 옛 공문을 학습시킬 때 **한꺼번에 매길** 수 있습니다. 고른 것 가운데 학년도가 없는 것이 몇 건인지도 알려 줍니다 |

## 2.1.0 — 워크플로우 연결을 끌어서

| | 설명 |
|---|---|
| **점을 끌어 잇기** | 상자를 **한 번 누르면** 테두리가 파래지고 **네 변 가운데에 파란 점**이 생깁니다. 그 점을 **끌어다 다른 상자에 놓으면** 화살표가 이어집니다. 끄는 동안 선이 커서를 따라오고, 놓을 상자는 **초록**으로 표시됩니다. 빈 곳에 놓거나 <kbd>Esc</kbd> 로 그만둡니다. [→ 연결] 단추는 없앴습니다 |

### 함께 고친 것

**끄는 도중 판이 아래로 밀리던 문제.** 연결을 시작하면 안내 띠가 나타나면서
판 전체가 **52px 아래로 밀려**, 끌던 손 밑에서 상자가 움직여 엉뚱한 곳에 놓였습니다.
안내 띠를 판 **위에 떠 있게** 바꿔 판이 움직이지 않도록 했습니다.

**고른 상자의 테두리 색이 안 바뀌던 문제.** `.wf-node.sel` 이 모양별 색(`.k-start` 등)
보다 앞에 있어 같은 무게로 밀렸습니다. 뒤로 옮겨 파란 테두리가 제대로 보입니다.

## 2.0.0 — 넘겨주기를 끝까지

1.x 는 **자료를 모으는** 프로그램이었습니다. 2.0 은 그것을 **넘겨주는** 데까지 갑니다.

| 기능 | 설명 |
|---|---|
| **📦 인수인계 꾸러미** | 버튼 하나로 **인수인계서가 완성됩니다.** 한 해 흐름(월별) · 업무별 진행 순서 · 겪어 보고 아는 요령 · 놓치면 안 되는 기한 · 공문 목록을 프로그램이 엮어 줍니다. 고쳐서 저장하고, **폴더 하나에 인수인계서(.txt) · 인수인계 파일(.db) · 받는 사람 안내문**을 함께 담아 넘깁니다. **AI를 쓰지 않아** 요금이 들지 않고 바로 나옵니다 |
| **🧹 새 학년도 정리** | 공문을 학습시킬 때 **몇 학년도 것인지 정해 두면**, 해가 바뀔 때 **그 학년도만 골라 지웁니다.** 전임자에게 받은 묵은 공문은 덜어 내고 내가 쌓은 것만 남깁니다. **워크플로우 · 서식 · 예시 · 직접 만든 문서 서식 · 가이드는 지우지 않습니다** — 해를 타지 않는 자산이니까요. 지우기 전에 백업을 자동으로 남깁니다 |
| **🔁 작년 이맘때** | 홈 화면에 **지난 학년도의 이맘때 했던 일**이 뜹니다. 쌓아 둔 자료가 '찾아보는 것'에서 '먼저 알려 주는 것'으로 바뀝니다. 처음 업무를 맡은 사람이 무엇이 다가오는지 알 수 있습니다 |
| **📅 날짜로 학년도 매기기** | 이미 쌓아 둔 공문에는 학년도가 없습니다. 버튼 한 번으로 **문서에서 찾은 접수일자를 보고 학년도를 매깁니다.** 날짜를 못 찾은 것은 [학년도 미지정]으로 모아 한꺼번에 처리합니다 |

### 함께 고친 것

**새로 넣은 자료의 id 가 0 으로 돌아오던 문제.** `addDoc` · `addTask` 같은 함수가
한 건씩 넣을 때 새 id 대신 0 을 돌려주고 있었습니다. sql.js 는 파일로 저장할 때
데이터베이스를 닫았다 다시 여는데, 그때 `last_insert_rowid()` 가 0 으로 되돌아갑니다.
저장한 **뒤에** id 를 읽고 있어서 늘 0 이었습니다. 저장 **전에** 읽도록 고쳤습니다.
그래서 [AI 없이 원문만 보관]으로 넣은 업무가 공문 원문과 이어지지 않던 것이 고쳐집니다.

# 🔧 프로그램을 고치거나 새 버전을 만들 때 (개발자용)

여기부터는 **코드를 수정할 때만** 필요합니다. 그냥 쓰실 거면 위 3단계로 충분합니다.

## 명령어는 어디에 붙여넣나요?

이 아래 나오는 회색 상자들은 전부 **터미널(명령 창)** 에 입력하는 것입니다.
"어디에 붙여넣지?" 싶으셨다면 아래 순서대로 하시면 됩니다.

### 윈도우에서 터미널 여는 법

1. 키보드에서 `Windows 키` 를 누릅니다
2. `powershell` 이라고 칩니다
3. **Windows PowerShell** 을 엽니다 → 검고 파란 창이 뜹니다

### 중요 — 반드시 "코드가 있는 폴더"로 먼저 이동해야 합니다

터미널을 갓 열면 엉뚱한 위치(예: `C:\Users\내이름`)에 있습니다.
그 상태로 명령어를 붙여넣으면 "그런 파일 없다"는 오류가 납니다.

코드를 내려받고 그 폴더로 이동하는 것까지 한 번에:

```powershell
cd $HOME\Desktop
git clone https://github.com/sced9120/work-dashboard.git
cd work-dashboard
```

이제 터미널 왼쪽에 `...\Desktop\work-dashboard>` 라고 보이면 준비 끝입니다.
**앞으로 나오는 모든 명령어는 이 창에, 이 위치에서** 실행합니다.

> 붙여넣기는 터미널 안에서 **마우스 오른쪽 클릭** 또는 `Ctrl+V` 입니다.
> 명령어 한 줄을 붙여넣은 뒤에는 꼭 **Enter** 를 눌러야 실행됩니다.

## 자료가 저장되는 곳

| | 경로 |
|---|---|
| 업무·공지 자료 | `%APPDATA%\work-dashboard\work-dashboard.db` |
| 자동 백업 | `%APPDATA%\work-dashboard\backups\` |
| API 키 | `%APPDATA%\work-dashboard\settings.json` (Windows DPAPI로 암호화) |

> 경로를 여는 법: `Windows 키 + R` → `%APPDATA%\work-dashboard` 입력 → Enter

자료 파일은 평범한 SQLite 파일이라 필요하면 DB 뷰어로도 열립니다.
예전 Streamlit 버전에서 쓰던 `school_admin_v25_final.db` 도 그대로 불러올 수 있습니다.
