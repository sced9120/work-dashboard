# 구글 설문지 연결 — 설계 (3.7.1 에서 만듦)

> 2026-11-13 정리, 2026-11-14 **3.7.1 에서 '추천' 길(①)로 만들었습니다.** 코드: `shared/relay.ts`(스크립트 v3 `form_` · `parseForm` · `sheetIdOf`), `electron/main/messenger.ts`(`relayForm`), `shared/seteuk.ts`(`formToSheet` — 머리글 다듬기 · 개인정보 문항 빼기), `src/components/SeteukImport.tsx`([구글 설문지] 탭). 시험: `t_relayform.cjs` · `run_relayform.cjs`.
> 만들면서 바꾼 것: 문항 → 입력 항목 칸 나누기는 아직 하지 않고 '문항: 답' 으로 관찰 기록에 붙인다. 전화 · 주소 · 생년월일 문항도 뺀다.

## 무엇을 하려는가

학생이 구글 설문지(Google Forms)로 낸 글 — 활동 소감, 탐구 계획, 보고서 요약, 자기 평가 — 을 오르빗 **세특 작성실**의 그 활동 · 그 학생 칸으로 바로 가져온다.
지금은 응답 시트를 엑셀로 내려받아 [관찰 기록 가져오기 → 엑셀 표 붙여넣기] 로 넣어야 해서, 활동마다 몇 단계를 손으로 거쳐야 한다.

## 지킬 것

- **학생 이름을 새로 구글로 보내지 않는다.** 응답 시트에는 학생이 쓴 이름 · 학번이 이미 들어 있다. 그 행을 *구글 → PC* 로 가져오기만 하고, PC 의 명단 · 세특 글은 구글로 올리지 않는다.
- 이 PC 의 명단과 맞추는 일(누가 누구인지)은 **PC 에서만** 한다. AI 에는 지금처럼 이름을 가린 글만 간다.
- 선생님 구글 계정 밖으로 나가는 것이 없다(별도 서버 · 앱 심사 없음). 이미 쓰는 **폰 우편함 스크립트**(선생님 계정의 Apps Script)를 다시 쓴다.
- 학생이 쓴 글은 교사 관찰이 아니다 → 관찰 기록에 `[설문]` 머리표를 붙여 가른다. 세특 초안 규칙(학생 자기 서술을 그대로 옮기지 않기)과 이어진다.

## 추천: 폰 우편함 스크립트에 '응답 시트 읽기'를 더한다 (스크립트 v3)

### 선생님이 하는 일

1. 오르빗 [세특 작성실 → 관찰 기록 가져오기 → **구글 설문지**] 를 연다.
2. 설문지의 **응답 시트 주소**(설문지 [응답] 탭 → 스프레드시트 아이콘으로 만든 시트)를 붙여 넣고, 넣을 **활동**을 고른다.
3. [가져오기] — 처음 한 번은 오르빗이 "폰 연결 코드를 새 판(v3)으로 바꿔 주세요" 라고 안내한다(아래 '권한').
4. 미리 보기에서 맞춘 학생 · 못 맞춘 줄을 보고 [넣기]. 다음부터는 같은 버튼으로 **새로 온 응답만** 가져온다.

### 흐름

```
오르빗(PC)                             우편함 스크립트(선생님 구글 계정)          응답 시트
  │  op=form&sheet=<시트 ID>&after=<마지막 제출 시각>  ─────►  │
  │                                       SpreadsheetApp.openById(ID)  ──►  첫 시트 읽기
  │  ◄─────  { ok, head:[머리글…], rows:[[…],…], last:<마지막 시각> }   (after 보다 뒤의 행만, 최대 300행)
  │
  ├─ 머리글로 칸 찾기: 학번 · 이름 · 반 · 번호 / 나머지는 문항
  ├─ matchNotes 와 같은 길로 명단과 맞추기 (학번 → 반 · 번호 → 이름이 하나뿐일 때 이름)
  ├─ 문항 → 활동의 입력 항목 칸 (문항 이름 = 입력 항목 이름이면 그 칸, 아니면 관찰 기록에 '문항: 답')
  └─ 관찰 기록 뒤에 '[설문 11/13] …' 로 붙이기 · 마지막 시각은 이 PC 에 기억 (활동마다)
```

- **새 응답만**: 행 번호 대신 응답 시트 첫 칸의 **타임스탬프**로 가른다(선생님이 중간 행을 지워도 어긋나지 않게). 같은 학생이 두 번 내면 둘 다 가져와 뒤에 잇고, 미리 보기에 "두 번 냄" 으로 보인다.
- **맞추기**: 이미 있는 `matchNotes`(엑셀 표 붙여넣기에 쓰는 것)를 그대로 쓴다 — 학번이 있으면 학번, 없으면 반 · 번호, 그것도 없으면 이름(명단에 하나뿐일 때만). 못 맞춘 줄은 넣지 않고 미리 보기에 보여 준다. 수업반(반별 목록)이 있으면 그 활동의 수업반 학생 중에서만 찾는다.
- **문항 → 칸**: 활동에 입력 항목이 여러 칸(예: 탐구 주제 · 결과와 오차)이면 같은 이름의 문항을 그 칸으로. 이름이 다르면 미리 보기에서 [문항 → 칸] 을 고를 수 있게 하고, 고른 것은 활동 설정에 기억한다. '이메일 주소' · '점수' 같은 칸은 빼 둔다.
- **긴 글**: 문항 답이 길면(예: 300자 넘음) 이미 있는 **보고서 요점 뽑기**(이름 가림 → 3~6줄)를 이어서 쓸 수 있게 [요점으로 줄이기] 를 미리 보기에 둔다.

### 스크립트 쪽 (v3 에 더할 것)

```js
// doGet 에 한 줄
if (p.op === 'form') return out_(form_(p.sheet, Number(p.after) || 0));

function form_(id, after) {
  if (!/^[A-Za-z0-9_-]{20,80}$/.test(String(id || ''))) return { ok: false, v: VER, error: '시트 주소가 맞지 않습니다.' };
  var sh = SpreadsheetApp.openById(id).getSheets()[0];
  var vals = sh.getDataRange().getDisplayValues();       // 화면에 보이는 글자 그대로
  var head = vals.shift() || [];
  var rows = [], last = after;
  for (var i = 0; i < vals.length && rows.length < 300; i++) {
    var t = Date.parse(vals[i][0]) || 0;                  // 첫 칸 = 타임스탬프
    if (t > after) { rows.push(vals[i]); if (t > last) last = t; }
  }
  return { ok: true, v: VER, head: head, rows: rows, last: last, more: rows.length >= 300 };
}
```

- 열쇠(`k`)가 맞아야만 답하는 것은 지금과 같다. 시트 ID 는 오르빗이 주소에서 뽑아 보내고, 스크립트는 **선생님 계정이 열 수 있는 시트만** 열 수 있다.
- 답이 크면(300행 넘음) `more: true` 로 알리고 오르빗이 `after=last` 로 한 번 더 묻는다.
- 타임스탬프 글자 모양은 시트의 지역 설정을 따르므로, 실제로 만들 때는 `getValues()` 의 Date 값으로 시각을 재고 나머지 칸만 `getDisplayValues()` 로 읽는다.

### 권한 · 판 올리기

- 스프레드시트를 읽는 권한이 **하나 늘어난다**(지금은 스크립트 저장소만 씀). 그래서 스크립트를 **v3** 로 올리고, 오르빗 카드의 [새 코드 복사] → 프로젝트에 덮어 붙여 넣기 → **배포 관리 → 새 버전** 으로 바꾸면 처음 한 번 구글이 권한을 다시 묻는다. 주소 · QR 은 그대로다.
- v2 스크립트를 쓰는 분은 [구글 설문지] 를 누를 때만 새 판 안내가 뜨고, 폰 관찰 · 출결은 그대로 쓴다.
- 학교 Workspace 계정은 관리자가 외부 앱 권한을 막아 두었을 수 있다 → 안내 글에 '개인 계정 권장' 을 지금처럼 둔다.

## 다른 길 (고르지 않은 까닭)

| 길 | 좋은 점 | 아쉬운 점 |
|---|---|---|
| **① 우편함 스크립트로 응답 시트 읽기 (추천)** | 이미 이어 둔 폰 연결을 그대로 씀 · 설치 한 번 · 선생님이 누를 때만 가져옴 | 권한 하나 늘어남(v3) |
| ② 설문지 제출 트리거(FormApp `onFormSubmit`) → 우편함에 쌓기 | 학생이 내자마자 PC 로(실시간) | 설문지마다 트리거 설치 · 설문지 편집 권한까지 필요 · 설문지를 바꾸면 다시 설치 · 학생 글이 우편함(속성 저장소)에 잠시 쌓임 |
| ③ 응답 시트를 xlsx 로 내려받아 [엑셀 표 붙여넣기] | 설정이 없고 **지금도 된다** | 활동마다 내려받기 · 고르기 · 붙여넣기를 손으로 · 새 응답만 고르기가 안 됨 |

①을 만들더라도 ③은 그대로 둔다(권한을 늘리고 싶지 않은 분 · 학교 계정).
