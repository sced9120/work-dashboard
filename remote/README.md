# 도구 모음 · 받은 테마 올리기 (업데이트 없이)

이 폴더의 **`catalog.json` 하나만 고치면**, 새 버전을 내지 않아도 모든 사용자의 프로그램에

- **[도구 모음]** 메뉴에 새 도구(세특 도우미 같은 것)가 생기고, 왼쪽 메뉴에 ● 표시가 뜹니다
- **[설정 → 화면 테마]** 아래 **받은 테마**에 새 색 묶음이 생깁니다
- 왼쪽 메뉴의 **[💬 의견 보내기]** 가 이 설문지로 열립니다 (v3.2.1 부터)

프로그램은 켤 때와 [도구 모음]을 열 때 **3시간마다** 이 파일을 새로 받습니다.
태그를 만들지 않으므로 배포(새 버전)가 아닙니다.

## 고치는 법 (GitHub 누리집에서)

1. 저장소에서 `remote/catalog.json` 을 열고 연필(✏️ Edit) 단추를 누릅니다
2. 아래 예시를 보고 `tools` 또는 `themes` 의 `[ ]` 안에 한 덩어리를 붙여 넣습니다
3. **Commit changes** 를 누릅니다 (main 에 바로)
4. 몇 분 뒤 저장소의 **Actions → 타입 검사** 가 초록 ✓ 이면 끝입니다.
   빨간 ✗ 이면 눌러서 **도구 모음 목록 검사** 줄을 보면 어디가 틀렸는지 한국어로 나옵니다.
   (틀린 항목은 프로그램이 그것만 빼고 씁니다. 파일 전체가 깨지면 마지막에 제대로 받은 목록을 계속 씁니다.)

> 여러 개를 넣을 때는 덩어리 사이에 **쉼표(,)** 를 넣고, 마지막 덩어리 뒤에는 쉼표를 넣지 않습니다.

## 도구 하나

```json
{
  "id": "setuk-helper",
  "name": "세특 도우미",
  "desc": "활동 기록을 붙여 넣으면 세부능력 및 특기사항 초안을 다듬어 줍니다.",
  "icon": "✍️",
  "url": "https://example.com/setuk",
  "category": "학생부",
  "tags": ["세특", "생기부"],
  "added": "2026-10-08",
  "by": "hsorbit"
}
```

| 칸 | 뜻 |
|---|---|
| `id` | 영문 소문자 · 숫자 · `-` 만. 한 번 정하면 바꾸지 마세요(메뉴에 고정한 사람의 바로가기가 이것으로 찾습니다) |
| `name` | 도구 이름 (40자까지) |
| `desc` | 한두 줄 설명 |
| `icon` | 이모지 한 개 (없으면 `""`) |
| `url` | **https://** 로 시작하는 주소. 브라우저에서 열립니다 |
| `category` | 묶음 이름. 같은 이름끼리 [도구 모음]에서 골라 볼 수 있습니다 |
| `tags` | 찾기용 낱말 |
| `added` | 올린 날. 30일 동안 **새로** 표시가 붙고 왼쪽 메뉴에 ● 이 뜹니다 |
| `by` | 만든 사람 (선택) |

주소나 이름을 고치면 다음에 받을 때 모두 따라 바뀝니다. 지우면 [도구 모음]에서 사라집니다.

## 받은 테마 하나

회색 벤토 · 글래스 · 기본 · 미드나잇 · 라벤더 가운데 하나의 **모양(base)** 에 **색만** 바꾼 것입니다
(`base`: `bento` · `glass` · `classic` · `midnight` · `lavender` — 미드나잇 · 라벤더는 v3.2.1 부터).
바꾸지 않은 색은 그 모양의 원래 색을 씁니다. `dark` 를 비워 두면 어둡게에서는 원래 색입니다.

```json
{
  "id": "forest",
  "name": "숲",
  "desc": "회색 벤토 모양에 짙은 초록 강조",
  "base": "bento",
  "light": {
    "--bg": "#dfe5df",
    "--surface": "#f6f8f5",
    "--accent": "#2f5d46",
    "--chip": "#2f5d46",
    "--raise": "#2f5d46"
  },
  "dark": {
    "--bg": "#1f2622",
    "--surface": "#2b3530",
    "--accent": "#9fd3b5",
    "--chip": "#9fd3b5",
    "--on-chip": "#10241a",
    "--raise": "#cfe8d9",
    "--on-raise": "#10241a"
  }
}
```

자주 쓰는 색 이름:

| 이름 | 어디 |
|---|---|
| `--bg` | 맨 뒤 바탕 |
| `--surface` · `--surface-2` · `--surface-3` | 카드 · 칸 바탕 (진하기 순) |
| `--text` · `--muted` | 글자 · 흐린 글자 |
| `--border` | 테두리 |
| `--accent` · `--on-accent` | 강조 단추와 그 위 글자 |
| `--chip` · `--on-chip` | 채운 칩 · 왼쪽 메뉴에서 고른 칸 |
| `--raise` · `--on-raise` | 오늘 패널의 맨 앞 카드처럼 튀게 하는 카드 |
| `--side-bg` · `--side-fg` | 왼쪽 메뉴 바탕 · 글자 (기본 모양) |

쓸 수 있는 이름 전체는 `shared/catalog.ts` 의 `THEME_VARS` 에 있습니다.
값에는 색(`#2f5d46`, `rgba(0, 0, 0, 0.1)`), 길이(`16px`), 그러데이션(`linear-gradient(160deg, #c3cce6, #93a2c8)`)만 쓸 수 있습니다.
주소 · 그림은 넣을 수 없게 막혀 있습니다.

## 의견 보내기 설문지 (v3.2.1 부터)

맨 바깥 `{ }` 안에 `"feedback"` 한 줄을 더합니다(`"themes": [...]` 뒤에 쉼표를 찍고).

```json
  "themes": [],
  "feedback": { "url": "https://docs.google.com/forms/d/e/.../viewform?usp=pp_url&entry.111111={version}&entry.222222={os}" }
```

- 주소가 있으면 모든 사용자의 왼쪽 메뉴 아래와 [설정]에 **💬 의견 보내기** 가 생깁니다. 지우면 단추가 사라집니다
- **버전 미리 채우기**: 구글 설문지 편집 화면 ⋮ → **미리 채워진 링크 받기** → '프로그램 버전' 문항 답에 `{version}`,
  '윈도우 버전' 문항 답에 `{os}` 라고 적고 [링크 받기] → 복사한 주소를 그대로 붙여 넣습니다.
  열 때 `{version}` 은 `3.2.1` 처럼, `{os}` 는 `Windows 10.0.26200` 처럼 바뀝니다(이름 · 학교는 보내지 않습니다)
- 미리 채우지 않으려면 설문지 주소만 넣어도 됩니다
